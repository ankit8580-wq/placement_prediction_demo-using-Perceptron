# Machine Learning Classification and Decision Boundary Visualization

## 📌 Overview
This project demonstrates a machine learning classification model using Python. It explores how a classifier separates different classes by visualizing decision boundaries and making predictions for new data points.

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- MLxtend

## 🚀 Features
- Train a machine learning classification model.
- Visualize decision boundaries using `plot_decision_regions()`.
- Predict the class of new data points.
- Calculate model accuracy using Scikit-learn.
- Visualize relationships between features using scatter plots.

## 🎯 Learning Objectives
- Understand classification algorithms.
- Learn how decision boundaries work.
- Practice model prediction and accuracy evaluation.
- Develop practical skills in machine learning visualization.

## ▶️ How to Run
1. Clone or download the repository.
2. Install the required libraries.
3. Open the Jupyter Notebook.
4. Run the cells sequentially to train the model, visualize decision boundaries, and make predictions.

## 📚 Applications
This project is useful for understanding supervised machine learning, classification, and model evaluation using Perceptron.
